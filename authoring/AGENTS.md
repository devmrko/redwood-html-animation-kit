# 발표 페이지 제작

이 폴더는 사용자의 발표를 만드는 로컬 프로젝트입니다. 먼저 [발표 장표 작성 원칙](SLIDE_PRINCIPLES.md), [제작 지침](AUTHORING.md), [제작 요청](REQUEST.md), `presentation-project.json`을 읽으세요. 작성 원칙과 장표 통과 기준을 기획·제작·검수에 적용하세요.

- 내용·목차·스크립트는 JSON, 실제 본문 화면은 `pages/*.js`에서 관리합니다. 고정 레이아웃 목록으로 표현을 제한하지 마세요.
- 제공된 템플릿과 공통 재생·발표자 보기·영상·SRT 인터페이스를 재사용하세요. 한글 글꼴·공식 로고·표지·간지·마지막 장을 유지하세요.
- 실제 브라우저에서 모든 페이지와 효과를 확인하고 잘림·겹침·빈 화면을 수정하세요. 확인하지 않은 동작을 완료했다고 보고하지 마세요.
- `.env`·키·개인 사진을 Git이나 외부 서비스에 올리지 마세요. 외부 모델·서비스 전송은 사용자가 승인한 범위를 따르세요.

실행: `python3 start.py --port 4173 --no-browser`. 이미 사용 중이면 다른 포트를 선택합니다. JSON·페이지 코드 변경 후 브라우저를 새로고침합니다. 서버 코드 변경 때는 서버도 재시작합니다.
