# 보완 기록 반영 설계

목표는 사용자가 작성한 발표를 같은 브라우저의 별도 청중 창과 발표자 보기로 실행하고, 구조화 내용·증거·탐색·배포를 공통 계약으로 연결하는 것이다. 근거는 사용자가 지정한 dataplatform_comparison의 `docs/41-redwood-kit-follow-up.md`이며 해당 프로젝트의 비공개 보고서·캡처는 키트에 복사하지 않는다.

## 완료 조건

- 기본 발표 시작은 현재 브라우저의 별도 창이며 준비 메시지를 받은 뒤 성공으로 표시한다. 원래 창을 청중 창으로 바꾸지 않는다. 팝업 차단·준비 실패를 표시한다. 기존 앱 모드는 선택 기능으로 유지한다.
- Reveal transform 배치 외에 2D 배치와 텍스트 이동 최소화 선택을 제공한다. 브라우저별 선명도를 보장하지 않고 1280·1920 실제 화면과 경계를 검수한다.
- 기존 v1 JSON에 목적·청중·판단, 페이지 역할·부모·구조화 데이터·핵심 메시지·증거 참조를 선택적으로 추가한다. 기존 문서는 유지하며 누락 참조·순환 관계를 거부한다. 페이지 코드가 데이터를 중복 복사하지 않도록 제작 지침과 편집 계약을 제공한다.
- 발표 사진 20개 제한을 증거에 재사용하지 않는다. 별도 파일 증거 manifest(최대 500개), 출처·촬영 성격·주장·SHA-256·용량과 안전한 상대 경로를 검증한다. 본문 증거와 원본 확대·Esc 복귀를 공통 부품으로 연결한다.
- 선택형 목차는 간지와 표시 계약을 구분한다. 상위 복귀·경로 탐색을 공통 API로 연결한다.
- 초안 ZIP 보호는 유지한다. 별도 CLI 명령으로 로컬에서 신뢰한 페이지 코드·참조 자산·출처·버전을 완성본 ZIP으로 묶고, 다른 폴더에서 실행한다. .env·미등록 파일·심볼릭 링크는 포함하지 않는다.
- 비교·상태·비용 표는 선택형 데이터 부품으로 제공하고 직접 HTML/SVG 제작을 유지한다. 다른 단위 비용을 자동 합산·동일 그래프로 비교하지 않는다.

## 검증

문서 계약·부모 순환·데이터 JSON 왕복, 증거 경로·용량·해시·31개 이상 처리, 팝업 준비/실패, 배포 ZIP 코드·의존 파일·증거 보존/비밀 제외를 자동 검사한다. 실제 브라우저에서 청중 창과 발표자 보기의 제어 대상, 탐색·확대·레이아웃을 확인한다. 실행하지 않은 브라우저·녹화는 완료로 보고하지 않는다.
