# 검증 범위

## 발표 키트 · 2026-11-18

자동 검사 87개(Node 35개·Python 52개)가 통과했습니다. 정적 검사에서 13개 샘플 페이지·33개 효과, 공통 모듈/CSS 해시와 연결 파일을 확인했습니다.

- AI 편집·목차·자막이 같은 OpenAI 호환 API·OCI CLI·설치된 Codex/Claude 연결을 사용하도록 요청 전달과 응답 검증을 검사했습니다.
- Mac 시작 파일은 공백이 있는 임시 경로에서 실제 실행해 자동 포트 선택·AI 설정 페이지·종료 시 연결 파일 정리를 확인했습니다.
- Chrome에서 Codex로 목차·자막을 생성하고, 장표 편집안의 비교·적용·복원을 확인했습니다. HTTP로 연 독립 발표 HTML에서 Python 편집 창으로 자료를 전달하는 흐름도 확인했습니다.
- 샘플 도구 모음의 줄바꿈과 밝은/어두운 목차 화면은 Chrome의 기본·800·640px 폭에서 확인했습니다.
- 버전 썸네일은 PNG 검증·불변 저장·서버 재시작 후 읽기·원본 복원 보존을 자동 검사했습니다. 썸네일 추가 후 브라우저 제어 연결이 응답하지 않아 실제 목록 표시·확대 화면은 아직 확인하지 못했습니다.

OCI 실제 모델 호출은 region·model·compartment 미설정으로 확인하지 못했습니다. Safari와 Windows 시작 파일의 실제 실행도 미확인입니다. 파일 직접 열기는 브라우저 제어 도구의 보안 제한으로 검증하지 못했으며 HTTP 검증과 구분합니다.

## 초기 Foundation · 2026-11-13

- Foundation lint·타입 검사·62개 단위 테스트·4개 생성기 테스트·빌드 통과.
- 독립 디렉터리에 core tarball만 설치해 공개 API/CSS export와 Vite 소비 빌드 통과.
- Edge에서 효과 버튼30개와 차트3개 클릭 완료 확인. 입력 레이블과 예제 전환, 글꼴 역할별 실제 크기 확인.
- 전체 화면 API의 진입/종료 상태 확인. Edge/macOS 창 전체 화면과 툴바 표시는 브라우저 설정의 영향도 받습니다.

전체 생성 앱(web/PWA/Android) 새 설치 검증은 npm 인증서 오류·오프라인 캐시 누락으로 완료하지 못했습니다. 위의 독립 core 소비 검증과 구분합니다.
실제 업무 데이터·외부 서버·다른 OS/실기기·영상 파일 내보내기는 확인하지 않았습니다.

공유본에서는 이전 회사명·협업 제안 문구를 제거했고, 수집 노드를 시멘틱 컨텍스트로 변경했습니다. 1페이지 카드의 본문 하단이 카드 경계 안에 있는지 실제 DOM 좌표로 확인했습니다.

정보 흐름은 세 열 상단30/하단590 기준선을 사용하며 SVG viewBox와 HTML640px 좌표계를 맞춥니다. 도착 토큰은 실제 슬롯 중심557/783px에 배치합니다.
