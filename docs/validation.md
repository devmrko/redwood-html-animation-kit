# 검증 범위

2026-11-13 로컬 검증입니다.

- Foundation lint·타입 검사·62개 단위 테스트·4개 생성기 테스트·빌드 통과.
- 독립 디렉터리에 core tarball만 설치해 공개 API/CSS export와 Vite 소비 빌드 통과.
- Edge에서 효과 버튼30개와 차트3개 클릭 완료 확인. 입력 레이블과 예제 전환, 글꼴 역할별 실제 크기 확인.
- 전체 화면 API의 진입/종료 상태 확인. Edge/macOS 창 전체 화면과 툴바 표시는 브라우저 설정의 영향도 받습니다.

전체 생성 앱(web/PWA/Android) 새 설치 검증은 npm 인증서 오류·오프라인 캐시 누락으로 완료하지 못했습니다. 위의 독립 core 소비 검증과 구분합니다.
실제 업무 데이터·외부 서버·다른 OS/실기기·영상 파일 내보내기는 확인하지 않았습니다.

공유본에서는 이전 회사명·협업 제안 문구를 제거했고, 수집 노드를 시멘틱 컨텍스트로 변경했습니다. 1페이지 카드의 본문 하단이 카드 경계 안에 있는지 실제 DOM 좌표로 확인했습니다.

정보 흐름은 세 열 상단30/하단590 기준선을 사용하며 SVG viewBox와 HTML640px 좌표계를 맞춥니다. 도착 토큰은 실제 슬롯 중심557/783px에 배치합니다.
