# Codex·Claude가 페이지를 제작하는 흐름

사용자가 시나리오·목차·페이지별 핵심 내용·스크립트를 작성하면, 도구는 템플릿과 공통 기능을 포함한 제작용 프로젝트를 내보낸다. Codex·Claude가 이 프로젝트에서 본문 HTML·CSS·SVG·JavaScript를 작성하고 실행해 화면을 검수한다. 앱의 LLM API는 선택형 내용 정리와 자막 초안에 사용한다.

## 완료 조건

- 편집한 발표 JSON·사진·템플릿·공통 코드·AGENTS.md·CLAUDE.md·제작 요청서를 하나의 ZIP으로 내보낸다. .env와 인증 정보, 다른 사용자의 발표는 포함하지 않는다.
- JSON은 제목·목차·내용·스크립트·요청을 관리하고, 페이지 코드는 별도 JS 모듈에 둔다. 고정 레이아웃으로 제한하지 않는다.
- 신뢰하는 로컬 페이지 코드만 앱 소유 모듈에서 명시적으로 등록한다. JSON을 불러오는 동작으로 임의 코드를 실행하지 않는다.
- 템플릿의 표지·간지·마지막 장·글꼴·로고·제목·여백을 유지한다. Codex·Claude는 본문 안에서 표·그림·도식·효과를 작성한다.
- 페이지는 공통 재생기와 시간·내용 추출 계약을 제공한다. 미리보기·발표자 보기·자막·MP4·SRT에 같은 페이지를 사용한다.
- 제작용 프로젝트를 별도 폴더에서 실행하고, 페이지 코드 변경과 JSON 스크립트 변경이 실제 화면 및 내보내기에 연결됨을 확인한다. 기본 본문은 제작 전 초안으로 명시한다.

## 구현 경계

공통 TypeScript 렌더러는 선택형 페이지 팩터리를 주입받는다. 팩터리는 DOM 마운트·메타데이터·사진을 받아 공통 PresentationTimeline을 반환한다. 호스트가 페이지와 프로젝트를 연결한다. 공통 Python 모듈은 명시된 공개 런타임 파일과 사용자가 선택한 프로젝트만 묶는다. ZIP 생성은 로컬에서 처리하며 API 키나 외부 모델이 필요하지 않다.

내보낸 루트의 presentation-project.json을 실행 시 로컬 저장소에 연결한다. 페이지 제작 후에는 JSON만으로 코드까지 전달되지 않으므로 프로젝트 폴더 전체를 보관한다. Codex·Claude의 실행·화면 검수가 완료되기 전에는 완성된 발표라고 표시하지 않는다.

## 확인한 범위

2026-11-17 실제 편집 화면에서 사진 1개·7장 문서의 제작용 ZIP(약 1MB)을 다운로드했다. 별도 폴더에 풀어 서버를 실행하고, 두 본문 모듈을 DOM 표·사진과 SVG 6단계 도식으로 바꿨다. 실제 Chrome에서 표시·일시정지·단계 이동과 발표자 보기의 장표·스크립트를 확인했다. 내보내기 화면에서 SVG 페이지의 화면 최소 23초와 자막 반영 27초를 확인했고, 전체 15개 자막이 포함된 SRT를 실제 저장했다. 새 페이지 모듈로 MP4를 다시 녹화하지는 않았으며 기존 녹화·변환 모듈을 그대로 사용한다.

자동 검사 39개(Node 18·Python 21), TypeScript 빌드, 링크·배포 파일 해시 검사와 diff 공백 검사를 통과했다. ZIP 검사에는 .env·다른 발표·비공개 사진·심볼릭 링크 제외와 잘못된 ID 거부를 포함한다. 이 기록은 위 검증용 문서의 결과이며 모든 사용자 요청의 페이지 품질을 보장하지 않는다.
