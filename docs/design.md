# 구성

공통 모듈은 Foundation 프레젠테이션 API와 CSS입니다. 배포 저장소에는 관련 원본을 `framework/`에 포함하고, 화면은 `vendor/foundation/`의 브라우저 모듈을 소비합니다.

- 재생기는 play/pause/restart/finish/destroy와 상태·현재 시각을 공통 계약으로 사용합니다.
- 갤러리는 효과를 바꾸기 전에 이전 재생기를 정리합니다.
- 기본 효과와 이동은 Web Animations API, 텍스트/SVG 확장은 주입한 Anime.js를 사용합니다.
- 차트는 데이터에서 SVG와 공통 타임라인 트랙을 생성합니다.
- 실제 데이터 수신·저장·승인은 구현하지 않는 데모입니다.

일반 웹 부품은 rem 단위로, 발표 장표는1600×900 좌표계로 구성합니다. 장표는 브라우저 가용 영역에 비율을 유지해 맞춥니다.
목차 너비를 제외한 영역 안에서 중앙에 배치하고, 전체 화면에서는 화면 전체를 사용합니다.
제공된 POTX의 글꼴 역할·색상·상단 패턴·좌우 여백을 참고합니다. 웹 UI와 발표용 글자 크기를 같은 규칙으로 취급하지 않습니다.

깊이 장면은 헤더/푸터와 격리합니다. 바닥 그림자는 카드 뒤에 두고, 강조 중인 카드는 높은 paint order를 사용한 뒤 원래 순서로 돌아갑니다.
