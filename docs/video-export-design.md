# 장표를 자막과 함께 영상으로 내보내기

장표 내용을 다시 제작하지 않고 기존 HTML 애니메이션을 MP4 영상으로 저장한다. 장표별 재생 시간과 자막을 사용자가 고친 뒤 저장하며, LLM은 선택한 장표의 제목·본문·발표 노트·실제 등장 시각으로 자막 초안을 만든다.

## 공통 계약과 앱 연결

2026-11-17 보완 설계: DOM 본문과 실제 타임라인의 요소별 등장 시각을 공통 context 모듈에서 추출한다. LLM 입력은 제목·본문·발표 노트·등장 시각이며, 출력은 원래 장표의 상대 시각을 사용한다. 기본 자동 읽기 모드는 자막마다 최소 2초 및 공백 제외 초당 6자 + 0.6초 여유라는 편집용 추정치를 확보한다. 가장 부족한 자막에 맞춰 장표·자막·애니메이션 시간을 같은 비율로 늘린다. 본문 공백 제외 14자/초 + 2초, 구성요소당 0.7초 + 2초, 단계당 3초 + 1초, 애니메이션 종료 후 1초, 마지막 등장 후 1.5~6초 중 최댓값을 화면 최소 시간으로 사용한다. 이 값은 검증된 읽기 속도가 아닌 조정 가능한 보수적 편집 기준이다. 실제 음성 길이를 분석하는 기능은 아니다. 수동 모드는 입력한 시각을 그대로 사용한다. 영상과 SRT는 하나의 계획을 공유하며, 화면에는 기본 시각과 적용 시각을 구분한다. 내보내기 최대 길이 10분은 늘어난 시간 기준으로 검증한다.

- `framework/src/presentation-context.ts`: DOM 본문·요소 수·단계 수와 애니메이션 keyframe의 등장 시각을 추출하고 화면 최소 시간을 계산한다.
- `framework/src/presentation-subtitles.ts`: 장표 계획 검증, 발표 노트 기반 초안, 자막 시간 검증, SRT 직렬화. DOM·특정 장표에 의존하지 않는다.
- `framework/src/presentation-video.ts`: 브라우저 탭에서 전달받은 요소만 캡처하고 1920×1080/30fps 캔버스로 녹화한다. 재생 순서는 호출자가 주입한다. 취소·캡처 종료·탭 숨김은 실패로 처리한다.
- `framework/src/presentation-window.ts`: 앱 모드 발표 창 실행 요청을 받는 공통 인터페이스. HTTP 경로는 앱이 주입한다.
- `framework/python/presentation_export.py`: 환경 설정·OpenAI 호환 자막 초안·FFmpeg MP4 변환·임시 작업 상태. 프레젠테이션 DOM이나 서버 핸들러에 의존하지 않는다.
- `main.js`: 현재 장표 목록과 재생 API만 노출한다. `export.html`·`export.js`는 그 API를 소비하고 편집·저장을 연결한다. `start.py`는 로컬 HTTP 어댑터다.

## 사용 흐름

영상 내보내기 → 목록에서 장표 선택 → 선택한 장표의 시간·자막 편집 → 노트 초안 또는 LLM 초안 → 미리보기 → 현재 탭 공유 선택 → 실제 시간 재생·녹화 → 로컬 FFmpeg 변환 → MP4·SRT·편집 설정 JSON 다운로드.

자막은 장표 내부 상대 시각으로 편집하고, 내보내기 때 포함된 장표의 누적 시각으로 변환한다. 재생 시간 변경으로 자막이 범위를 벗어나면 자동 절단하지 않고 수정을 요구한다. 자막은 영상에 표시하거나 MP4 선택형 트랙 또는 SRT 파일로 저장한다. 현재 범위는 무음 영상이다.

## 경계와 검증

- 브라우저 키·서버 키 노출 금지. `.env`는 로컬 서버만 읽고 정적 파일로 제공하지 않는다. `OPENAI_API_KEY`/`OPENAI_BASE_URL`/`OPENAI_MODEL` 및 기존 `OPENROUTER_API` 이름을 지원한다.
- 초안 생성 버튼을 누를 때만 제목·본문·노트·등장 시각을 설정한 제공자에 전송한다. 오류 응답에 원격 응답 본문이나 인증값을 포함하지 않는다. 생성 결과의 시간·내용은 편집 가능하다.
- 영상 업로드·작업 생성은 동일한 로컬 origin만 허용한다. 파일 이름·경로·FFmpeg 인자를 요청에서 직접 받지 않는다. 작업은 임시 디렉터리와 단일 변환 worker를 쓰며 서버 재시작 후 복구를 보장하지 않는다.
- 캡처는 Chromium의 현재 탭 영역 자르기를 사용한다. 화면 전체·다른 탭을 선택하면 내보내지 않는다. 녹화 시간은 영상 길이만큼 필요하며 취소한 결과를 완료로 표시하지 않는다.
- 자막 경계·서로 겹치는 시간·계획 순서·SRT 시각, 잘못된 LLM 응답·비밀 파일 접근 차단, 실제 FFmpeg 출력의 해상도·프레임률·선택형 자막 트랙을 검증한다. 브라우저에서는 짧은 장표 한 장의 캡처·취소·다운로드를 확인한다.

## 구현 상태

검증: TypeScript 빌드, 장표 13개·효과 33개·연결 파일 34개 정적 검사, Node 자막/시간 계획 검사 6건과 Python 서버/LLM/FFmpeg 검사 9건 통과. 실제 OpenRouter 저비용 모델로 본문·노트·등장 시각을 전달해 초안을 생성했고, 실제 H.264 1920×1080/30fps MP4의 한글 mov_text 트랙과 SRT를 추출해 확인했다. Chromium 탭에서 18초 장표 캡처와 MP4 변환도 확인했다. 브라우저에서 장표 데이터 연결과 적용 시간 표시를 확인했다. LLM의 의미별 시각 배치는 초안이므로 사용자가 검토한다. 본문은 HTML/SVG 텍스트만 추출하며 이미지 OCR과 음성 합성은 포함하지 않는다. CSS 전용 반복 애니메이션·외부 영상은 현재 플레이어 속도 제어 계약에 포함되지 않는다.

## 사용자 제공 HTML 참고 검토

2026-11-17 제공된 Oracle 엔지니어 세션 HTML의 구조를 읽었다(83개 장표, 단계형 화면 9개, SVG 42개, video 4개). 원본 전체나 내장 미디어는 저장소에 복사하지 않는다. 섹션·소주제 표시는 간지 외에 각 장표의 위치를 설명하는 구성 요소이고, 도식과 현재 단계 설명을 나란히 강조하는 형태는 본문용 구성이다. 단계 수(`data-steps`, `data-s`)·표 행·SVG 텍스트를 화면 최소 시간 추정에 반영했다. 섹션 머리말·비교/지표 구성·단계별 수동 탐색은 추가 구성 후보이며 이번 구현에 새 장표로 포함하지 않았다. 내장 영상 자동 재생·길이 반영과 CSS 단계 애니메이션의 영상 내보내기는 별도 어댑터가 필요하다.
