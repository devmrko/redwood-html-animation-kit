# v0.1.0-alpha.2

HTML 발표자료를 만들고 발표·PPT·자막 영상으로 저장하는 흐름의 오류를 보완한 알파 버전입니다. 이전 `v0.1.0-alpha.1`의 저장소 구성과 샘플 13장·효과 33종을 유지합니다.

## 시작하기

릴리스의 키트 ZIP을 전부 풀고 Python 3로 `python3 start.py`를 실행합니다. 출력된 로컬 주소에서 샘플을 확인하고 [사용법 데모와 제작 순서](../../README.md)를 따라 진행합니다. 기본 샘플에는 npm·API 키가 필요하지 않습니다. 사용법 데모 복사·AI 이력에는 Git, 영상 변환에는 FFmpeg, AI 호출에는 선택한 제공자의 설정이 필요합니다.

저장소의 편집·AI·내보내기는 Python 서버를 사용합니다. 완성한 발표자료에서 별도로 생성한 발표용 ZIP은 `index.html`에 실행 코드를 포함합니다. 두 ZIP을 구분해 사용하세요.

## 주요 변경

- 발표 창과 발표자 창의 새로고침·종료 후 연결, 도구 모음 줄바꿈과 검색/브라우저 단축키를 보완했습니다.
- 공통 표의 여백·상태 표시를 통일하고 차트가 본문 아래로 잘리는 문제를 수정했습니다.
- 화면 유지형 PPT에서 SVG 테마 색과 보조선이 빠지는 캡처 오류를 수정했습니다. 완료·실패 후 원본 SVG 속성을 복원합니다.
- AI 편집안 취소, 저장 중 닫기 차단, 외부 원본 변경 충돌, 최신 버전 다시 불러오기를 보완했습니다. 응답이 끊겼을 때 자동으로 같은 저장을 반복하지 않습니다.
- OCI 리전·모델·프로파일·컴파트먼트 이름/OCID를 `.env`에서 설정할 수 있습니다. 키와 개인 설정은 배포본에 포함하지 않습니다.
- 영상 녹화에 포인터 제외를 요청합니다. 미지원 환경에서는 포인터가 포함될 수 있습니다.

## 확인한 범위

- 자동 검사 120개(Node 48·Python 72), TypeScript 빌드·배포 동기화와 정적 검사.
- Chrome의 5개 iframe 크기 × 2테마 × 2화면 모드 × 8구성, 총 160개 배치 검사. 기존 효과 33종·표 4개 조합.
- Mac PowerPoint에서 실제 PPT 두 방식의 배치와 지정 글꼴, 표·사진·차트·동영상 정지 화면 확인.
- 실제 자막 포함 MP4 49.6초와 SRT 일치, 긴 자막 장표 6.5초 → 18.499초 확보. 선택형 자막 MP4 12.1초의 트랙·문구·시각 대조.
- 실제 Codex·Claude·OCI의 제목/표 수정·적용·새 버전 복원. 공개 합성 자료만 사용했습니다.
- HTTP 응답을 생성/저장 직후 끊어 원본 보존·최신 상태 확인·중복 저장 방지를 검증했습니다.
- ZIP만 푼 정적 폴더의 검색·로컬 영상·발표자 대본 동기화.
- 개인 `.env`가 없는 새 키트 추출 폴더의 Python 실행·샘플 13장·사용법 데모 11장 복사·내보내기 연결·SRT 다운로드.

## 알려진 제한과 남은 검증

- 파일 더블클릭 실행과 Windows는 이번 환경에서 검증하지 못했습니다. 정적 HTTP 검증을 파일 실행의 통과로 보지 않습니다.
- 실제 초보 사용자의 독립 사용성 시험, 실기기 모바일, Reveal 배치와 재생기별 선택형 자막 UI 검수가 남아 있습니다.
- 편집형 PPT는 HTML과 줄바꿈이 달라질 수 있습니다. 글꼴 파일을 포함하지 않으며 복잡한 그래픽·애니메이션·동영상은 정지 화면으로 남습니다.
- OpenAI 호환 nano 모델은 제목 수정에 성공했지만 표의 행·열 의미를 잘못 구성했습니다. 미리보기와 내용 검수가 필요합니다. 모든 모델의 성공을 보장하지 않습니다.
- 생성 응답을 받지 못하면 서버에 미적용 편집안이 남을 수 있습니다. 모델 작업·과금 취소는 보장하지 않습니다. 저장 응답이 끊겼다면 최신 버전을 불러와 결과를 확인합니다.
- MP4는 무음이며 YouTube 장표는 녹화에서 제외해야 합니다. 전체 영상은 자동 시간 조정 후 최대 10분입니다.
