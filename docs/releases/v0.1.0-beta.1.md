# v0.1.0-beta.1

예제를 수정해 발표하고 PPT·자막 영상으로 저장하는 흐름을 소수 사용자와 확인하기 위한 베타입니다. [알파 2의 기능과 수정 사항](v0.1.0-alpha.2.md)을 포함하며, 이번 전환에서는 Ubuntu 자동 검증을 추가했습니다.

## 시작하기

저장소를 내려받아 전체 폴더를 풀고 `python3 start.py`를 실행합니다. 출력된 로컬 주소에서 [사용법 데모와 제작 순서](../../README.md)를 따라 진행합니다. 기본 샘플에는 npm·API 키가 필요하지 않습니다. 데모 복사·AI 이력은 Git, 영상 변환은 FFmpeg, AI 호출은 선택한 제공자의 설정이 필요합니다.

편집용 키트는 Python 서버로 실행합니다. 완성 자료에서 생성하는 발표용 ZIP은 별도 배포본이며, 파일 직접 실행은 아래 미검증 범위를 확인하세요.

## 변경 사항과 검증

- GitHub Actions에서 Node 22·Python 3.12·FFmpeg/FFprobe로 TypeScript 빌드, 브라우저 배포 파일 동기화, 자동 검사와 정적 검사를 실행합니다.
- 베타 태그 대상 `d853ec4`의 [CI 실행이 통과했습니다](https://github.com/devmrko/redwood-html-animation-kit/actions/runs/44483490675). 자동 검사는 Node 48개·Python 72개입니다.
- Mac Chrome·PowerPoint 실화면, 표·사진·차트·영상 배치, PPT 두 방식, MP4·SRT, AI 적용·복원의 기존 검증 범위는 [상세 기록](../validation.md)을 따릅니다. CI 통과만으로 브라우저·PowerPoint 실화면을 검증했다고 보지 않습니다.

## 알려진 제한과 피드백

- 파일 더블클릭과 Windows, 실기기 모바일, Reveal 배치, 실제 초보 사용자의 독립 검증이 남아 있습니다.
- 편집형 PPT는 글꼴 환경에 따라 줄바꿈이 달라질 수 있습니다. 글꼴 파일은 포함하지 않으며 복잡한 그래픽·애니메이션·동영상은 정지 화면으로 남습니다.
- AI 결과는 적용 전 미리보기에서 내용·수치·표의 행과 열을 확인해야 합니다. 모델별 품질 차이가 있으며 응답이 끊기면 최신 버전을 불러와 저장 결과를 확인합니다.
- MP4는 무음이며 YouTube 장표는 녹화에서 제외해야 합니다. 자동 조정 후 영상 길이는 최대 10분입니다. 선택형 자막 UI는 재생기별 검수가 남아 있습니다.

문제가 있으면 사용 환경(OS·브라우저·파일/서버 실행), 재현 순서, 기대 결과와 실제 결과를 함께 알려주세요. API 키·`.env`·개인 자료는 첨부하지 않습니다. 다음 작업은 [베타 개선 순서](../alpha-roadmap.md)를 따릅니다.

## 태그와 문서 버전

공개한 `v0.1.0-beta.1` 태그는 `d853ec4`를 가리키며 변경하지 않습니다. 태그를 먼저 생성해 해당 시점의 README·패키지 버전에는 `alpha.2` 표기가 남아 있습니다. 이 문서와 `main`의 README·패키지 버전에서 베타 표기를 보완했습니다. 기존 알파 2 릴리스 ZIP은 당시 기록으로 유지하며 베타 배포본으로 바꾸지 않습니다.
